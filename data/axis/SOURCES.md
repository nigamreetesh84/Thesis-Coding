# Axis Bank eligibility data: sources and status

Compiled 22 Nov 2026 for the round 7 bank-portal demonstration and the federated-learning
leave-one-bank-out test. **Status: DRAFT, to be verified by the author against the live
Axis Bank pages before any number is reported.** Set `verified_by_author` to TRUE in
`eligibility_axis.csv` after checking each row.

| Card | Field | Value used | Source |
|---|---|---|---|

Findings worth reporting (real-document gap, cf. SBI/HDFC):
- Axis publishes AGE on its own card pages; INCOME mostly comes from aggregators; no card-specific CIBIL threshold.
- Flipkart Axis has different income thresholds for salaried and self-employed applicants. The frozen
  schema holds one income per card, so the lower (salaried) value is kept and self-employed applicants
  between Rs 1.8 and 3.6 lakh would be wrongly shown as eligible: a schema limitation to report.
- Magnus shows real rule drift (Rs 18 lakh -> Rs 24 lakh); the superseded value must be ignored.

Demo files in `data/portal_samples/` are generated by `python -m src.portal.samples` (amounts written
as "Rs" because the PDF font has no rupee glyph). The ILLUSTRATIVE update file is NOT a real Axis change.
